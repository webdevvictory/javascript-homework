## 📘 Introduction to JavaScript

В этом конспекте ты познакомишься с основами программирования и языком JavaScript, установишь необходимое ПО и напишешь первый простой код.

---

# 🧠 1. Что такое язык программирования

**Язык программирования** — это способ общения с компьютером, с помощью которого человек задаёт инструкции.

📌 Проще говоря:
это «язык», на котором ты объясняешь компьютеру, что нужно сделать.

---

## 📦 Примеры задач:

* вывести текст
* выполнить расчёт
* обработать данные

---

👉 Важно:
Компьютер не понимает «человеческий язык» напрямую — ему нужны точные инструкции.

---

# 🤖 2. Что такое JavaScript

**JavaScript** — это язык программирования, который широко используется для создания приложений.

---

## 📌 Где используется JavaScript:

* веб-сайты (в браузере)
* серверные приложения
* автоматизация
* работа с API

---

👉 Важно:
JavaScript — один из самых популярных языков, особенно для начинающих.

---

# ⚙️ 3. Установка необходимого ПО

Для начала работы нужно установить несколько инструментов.

---

## 🔹 3.1 Node.js

**Node.js** — это среда выполнения JavaScript вне браузера.

---

### 📦 Что это даёт:

* запуск JS-кода на компьютере
* работа с файлами
* создание серверных приложений

---

### 📌 Что нужно сделать:

1. Скачать Node.js с официального сайта
2. Установить
3. Проверить установку

---

### 🧪 Проверка:

Открой терминал и введи:

```
node -v
```

Если отображается версия — всё работает.

---

---

## 🔹 3.2 Visual Studio Code

**Visual Studio Code (VS Code)** — это редактор кода.

---

### 📦 Что это даёт:

* удобное написание кода
* подсветка синтаксиса
* расширения

---

### 📌 Что сделать:

1. Скачать и установить
2. Открыть папку проекта

---

---

## 🔹 3.3 Prettier

**Prettier** — это инструмент для автоматического форматирования кода.

---

### 📦 Что это даёт:

* красивый и единый стиль кода
* автоматическое исправление форматирования

---

### 📌 Установка:

1. Открыть VS Code
2. Перейти в Extensions
3. Найти Prettier
4. Установить

---

👉 Важно:
Prettier не влияет на работу программы — только на внешний вид кода.

---

# 🧾 4. Первый код на JavaScript

Теперь напишем простой пример.

---

## 📦 Шаг 1: создать файл

Создай файл:

```
index.js
```

---

## 📦 Шаг 2: написать код

```javascript
console.log("Hello, world!");
```

---

## 📌 Что это значит:

* `console.log` — команда вывести текст
* `"Hello, world!"` — сам текст

---

---

## ▶️ Шаг 3: запустить

Открой терминал в папке с файлом и введи:

```
node index.js
```

---

## 📊 Результат:

```
Hello, world!
```

---

👉 Важно:
Это твоя первая работающая программа 🎉

---

# ⚠️ 6. Частые ошибки

## ❌ Node.js не установлен

→ команда `node` не работает

---

## ❌ файл не сохранён

→ код не запускается

---

## ❌ ошибка в названии файла

→ команда не находит файл

---

# 🧠 Важные выводы

* язык программирования — это способ давать инструкции компьютеру
* JavaScript — популярный и универсальный язык
* Node.js позволяет запускать JS вне браузера
* VS Code — удобный редактор
* Prettier — инструмент для форматирования
