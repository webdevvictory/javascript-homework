## 📘 Objects and JSON

В этом конспекте ты познакомишься с объектами — одним из ключевых типов данных в JavaScript, а также с форматом JSON, который широко используется для передачи данных.

---

# 🧠 1. Что такое объект (Object)

**Объект (object)** — это структура данных, которая хранит набор значений в формате «ключ — значение».

📌 Проще говоря:
объект — это «набор связанных данных в одной коробке».

---

## 📦 Пример:

```javascript id="obj1"
let user = {
  name: "Ivan",
  age: 25,
  isAdmin: true
};
```

---

## 📌 Что здесь происходит:

* `user` — переменная
* `{}` — объект
* `name`, `age`, `isAdmin` — ключи
* значения — данные

---

👉 Важно:
Объект объединяет несколько значений под одним именем.

---

# 🎯 2. Зачем нужны объекты

Объекты используются, когда нужно:

* хранить связанные данные
* описывать сущности (например, пользователь, товар)
* структурировать информацию

---

## 📦 Пример:

```javascript id="obj2"
let product = {
  name: "Phone",
  price: 300,
  quantity: 2
};
```

---

👉 Это удобнее, чем хранить всё в отдельных переменных.

---

# 🔧 3. Работа с объектами

---

## 🔹 3.1 Доступ к данным

```javascript id="obj3"
console.log(user.name);
console.log(user.age);
```

---

👉 Используется точка (`.`)

---

---

## 🔹 3.2 Изменение значений

```javascript id="obj4"
user.age = 26;
```

---

---

## 🔹 3.3 Добавление новых свойств

```javascript id="obj5"
user.email = "ivan@example.com";
```

---

---

## 🔹 3.4 Использование в вычислениях

```javascript id="obj6"
let total = product.price * product.quantity;
```

---

👉 Объекты можно использовать так же, как обычные переменные.

---

# 🧱 4. Вложенные объекты

Объекты могут содержать другие объекты.

---

## 📦 Пример:

```javascript id="obj7"
let user = {
  name: "Ivan",
  address: {
    city: "Belgrade",
    country: "Serbia"
  }
};
```

---

## 📌 Доступ:

```javascript id="obj8"
console.log(user.address.city);
```

---

👉 Важно:
Можно строить сложные структуры данных.

---

# 🌐 5. Что такое JSON

**JSON (JavaScript Object Notation)** — это формат представления данных.

📌 Он похож на объект, но используется для передачи данных между системами.

---

## 📦 Пример JSON:

```json id="json1"
{
  "name": "Ivan",
  "age": 25,
  "isAdmin": true
}
```

---

## 🧠 Важно:

JSON:

* используется для обмена данными
* является текстом
* имеет строгий формат

---

# ⚠️ 6. Отличие объекта от JSON

| Объект (JavaScript)          | JSON                      |
| ---------------------------- | ------------------------- |
| используется в коде          | используется для передачи |
| ключи могут быть без кавычек | ключи всегда в кавычках   |
| может содержать функции      | только данные             |

---

👉 Важно:
JSON — это **не переменная**, а формат данных.

---

# 🔄 7. Преобразование: Object ↔ JSON

---

## 🔹 7.1 Объект → JSON

```javascript id="json2"
let user = {
  name: "Ivan",
  age: 25
};

let json = JSON.stringify(user);
```

---

👉 Результат:

```javascript id="json3"
'{"name":"Ivan","age":25}'
```

---

---

## 🔹 7.2 JSON → объект

```javascript id="json4"
let json = '{"name":"Ivan","age":25}';

let user = JSON.parse(json);
```

---

👉 Теперь это снова объект.

---

# 🧪 8. Практический пример

```javascript id="obj9"
let order = {
  product: "Laptop",
  price: 1000,
  quantity: 2
};

let total = order.price * order.quantity;

console.log("Total: " + total);

let json = JSON.stringify(order);

console.log(json);
```

# ⚠️ 10. Частые ошибки

## ❌ Ошибка в JSON

```json id="err1"
{
  name: "Ivan"
}
```

👉 Ошибка: нет кавычек у ключа

---

---

## ❌ Неправильный доступ

```javascript id="err2"
console.log(user.adress);
```

👉 Ошибка в названии поля

---

---

## ❌ Попытка работать с JSON как с объектом

```javascript id="err3"
let json = '{"name":"Ivan"}';

console.log(json.name); // undefined
```

---

👉 Нужно сначала `JSON.parse`

---

# 🧠 Важные выводы

* объект — это структура «ключ — значение»
* используется для хранения связанных данных
* JSON — это формат передачи данных
* объект ≠ JSON
* можно преобразовывать:

  * объект → JSON
  * JSON → объект
* дебаггер помогает понимать структуру данных
