## 📘 Variables and Data Types

В этом конспекте ты познакомишься с основами работы с данными в программировании: переменными и типами данных. Это фундамент, без которого невозможно писать программы.

---

# 🧠 1. Что такое переменная

**Переменная (variable)** — это именованное место в памяти компьютера, в котором хранится значение.

📌 Проще говоря:
переменная — это «коробка», в которую можно положить данные.

---

## 📦 Пример:

```javascript
let name = "Ivan";
```

---

## 📌 Что происходит:

* `name` — имя переменной
* `"Ivan"` — значение
* `let` — команда создать переменную

---

👉 Важно:
Ты можешь использовать переменную позже в программе.

---

# 🎯 2. Зачем нужны переменные

Переменные позволяют:

* хранить данные
* переиспользовать значения
* делать код гибким

---

## 📦 Пример:

```javascript
let price = 100;
let quantity = 3;

let total = price * quantity;
```

---

👉 Без переменных код был бы неудобным и негибким.

---

# 🧱 3. Типы данных

**Тип данных** — это вид значения, которое хранится в переменной.

📌 Проще:
тип показывает, **что именно хранится**.

---

## 🔹 Основные типы в JavaScript:

---

### 📌 3.1 Number (число)

```javascript
let age = 25;
let price = 99.99;
```

👉 Используется для:

* расчётов
* числовых значений

---

### 📌 3.2 String (строка)

```javascript
let name = "Ivan";
let message = "Hello";
```

👉 Используется для:

* текста

---

### 📌 3.3 Boolean (логический тип)

```javascript
let isActive = true;
let isAdmin = false;
```

👉 Используется для:

* условий
* логики

---

### 📌 3.4 Null и Undefined (базово)

```javascript
let value = null;
let data;
```

👉 Используются, когда:

* значение отсутствует

---

👉 Важно:
Тип данных влияет на то, **что можно делать с переменной**.

---

# ➕ 4. Операции с переменными

---

## 🔹 4.1 Математические операции

```javascript
let a = 10;
let b = 5;

let sum = a + b;        // 15
let diff = a - b;       // 5
let product = a * b;    // 50
let division = a / b;   // 2
```

---

👉 Важно:
работают только с числами.

---

---

## 🔹 4.2 Конкатенация (объединение строк)

```javascript
let firstName = "Ivan";
let lastName = "Petrov";

let fullName = firstName + " " + lastName;
```

---

## 📊 Результат:

```javascript
"Ivan Petrov"
```

---

👉 Важно:
оператор `+` может объединять строки.

---

---

## 🔹 4.3 Смешанные операции

```javascript
let name = "Ivan";
let age = 25;

let result = name + " is " + age + " years old";
```

---

👉 JavaScript автоматически преобразует число в строку.

---

# 🧪 5. Практический пример

```javascript
let productName = "Phone";
let price = 300;
let quantity = 2;

let total = price * quantity;

console.log(productName + " total price: " + total);
```

---

## 📊 Результат:

```javascript
Phone total price: 600
```

---

# 🐞 6. Использование дебаггера

**Дебаггер (debugger)** — это инструмент, который позволяет:

* выполнять код пошагово
* смотреть значения переменных

---

## 🔧 В Visual Studio Code

---

### 📌 Как использовать:

1. Открой файл
2. Поставь breakpoint (точку остановки)
3. Запусти Debug

---

## 📦 Пример кода:

```javascript
let a = 10;
let b = 5;

let result = a + b;

console.log(result);
```

---

---

## 🧠 Что можно увидеть:

* значения `a`, `b`, `result`
* как меняются данные
* порядок выполнения

---

## 📊 Что происходит в памяти:

```text
a → 10
b → 5
result → 15
```

---

👉 Важно:
переменные реально хранятся в памяти во время выполнения программы.

---

# ⚠️ 7. Частые ошибки

## ❌ Использование несуществующей переменной

```javascript
console.log(x);
```

---

## ❌ Путаница типов

```javascript
let result = "10" + 5; // "105"
```

---

## ❌ Забыли объявить переменную

→ ошибка выполнения

---

# 🧠 Важные выводы

* переменная — это место для хранения данных
* тип данных определяет, как используется значение
* основные типы: number, string, boolean
* можно выполнять:

  * математические операции
  * конкатенацию строк
* debugger помогает понять, как работает программа
