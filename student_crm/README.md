# Student CRM

Система управления студентами.

## Возможности

- Просмотр списка студентов
- Просмотр информации о каждом студенте
- Отображение статуса обучения
- Подсчёт общего количества студентов

## Технологии

- React
- JavaScript
- HTML
- CSS
- Vite

## Установка и запуск

1. Клонировать репозиторий.
2. Установить зависимости:

   ```bash
   npm install
   ```

3. Запустить проект:

   ```bash
   npm run dev
   ```
